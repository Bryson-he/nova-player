Fixes for the stuff that annoys you

These are the most common complaints about Jellyfin Media Player, each one fixed.

No more freezing on Play

The player opens instantly. Every server request runs in the background with a timeout, and you can always back out while it loads. If your PC can't play a file directly, Nova switches to server transcoding on its own instead of hanging.

Sorting that sticks

Each library remembers its own sort, order, filter, genre and card size, even after a restart. Going back keeps your exact scroll position, and big libraries get an A–Z jump bar.

Tracks remembered per series

Pick Japanese audio and English subtitles once, and every episode follows. Nova matches tracks by language, title, forced/SDH and commentary, not by position, so it still works when episodes order their tracks differently.

Everything else you'd expect

Plus a few things you've probably wished Jellyfin had.

  • Skip Intro / Recap button, or auto-skip (Jellyfin media segments or Intro Skipper)
  • Up Next countdown when the credits start, with auto-play
  • Trickplay thumbnails when hovering the seek bar
  • Subtitle size, colour, background, position and outline
  • Live subtitle sync adjustment (Z / X)
  • PGS / VobSub image subtitles burned in automatically
  • Instant audio-track switching while direct playing
  • Quality and playback-speed menus
  • Shuffle a show or a whole library
  • Remove items from Continue Watching
  • "Ends at" time on every movie and episode
  • Picture-in-picture and media-key support
  • Screen stays awake during playback
  • Quick Connect sign-in; login encrypted with Windows DPAPI
  • Remembers volume, window size and position
  • Automatic updates from GitHub Releases
